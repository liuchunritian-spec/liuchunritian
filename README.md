## 当前项目

### Temu 核价计算器（`temu-核价计算器.html`）

单文件网页工具，浏览器双击打开就能用，无需安装任何东西。

**功能：**
- 输入进货成本、头程、包装等费用，自动算出**保本申报价**和**建议申报价**
- 填上平台推荐价，自动判断：亏本（红）/ 利润不够（黄）/ 可以接（绿）
- 支持汇率、目标利润率、Temu 佣金率

**怎么用：** 打开 HTML 文件，填数字，看结果。核价单价格低于保本价就别接。

## 学习笔记

- **commit** = 一次存档，`git log` 可以看全部历史
- **push** = 把本地存档推到 GitHub 云端
- **clone** = 把云端仓库下载到电脑
- 仓库既存代码也存历史，改坏了随时能回到任何一版
